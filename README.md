# Pokémon Browser React App

This project implements a Pokémon browser interface similar to the Pokémon website. It allows users to browse Pokémon in different view modes (grid and list) and sort them by various criteria.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in the interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.

## Project Structure

The project follows the standard React application structure with components organized in a modular way.

## Features

- Grid and List view modes
- Sorting functionality
- Responsive design
- Pokémon card displays with type, number, and name
